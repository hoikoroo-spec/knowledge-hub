# Knowledge Hub v0.4

会話・メモを一時保管し、整理案を編集して登録候補にする個人向けPWAの初期版です。

## 使い方
GitHub Pagesで公開する場合、リポジトリのルートにこの3ファイルを置き、Settings → Pages → Deploy from a branch → main / (root) を選択します。

- 「＋ 会話」→ 入力 →「発言を保存」で発言を保存
- 「＋ メモ」→ 入力すると自動保存
- 「整理案を作る」→ 整理案を編集 →「登録候補として保管」
- 検索、削除、JSONバックアップと読み込みが可能

## 制限
- 会話は発言の記録のみ。AIからの返答はありません。
- 整理案は簡易な文字列抽出であり、AI処理ではありません。
- データは各端末のブラウザの localStorage に保存され、端末間同期はありません。
- Notion登録、認証、音声会話は未実装です。
- GitHub PagesにAPIキーを埋め込まないでください。AIやNotion連携には認証付きバックエンドが必要です。
- 機密情報や会社の非公開情報は入力しないでください。
